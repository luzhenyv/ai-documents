# 《从 0 和 1 到 AI》

**产品是 19 篇图文稿**：正片 EP01–EP17，番外 X01、X02。一集一个文件夹，稿和配图一起打磨。

| 目录 | 是什么 |
|---|---|
| [series/](series/README.md) | **成稿**。打开某一集即可改字、对图。配图规矩见 [SOP-配图](series/SOP-配图.md) |
| [shorts/](shorts/README.md) | 衍生短视频「AI 原来如此」，从长稿重写，不是切片 |
| [sources/](sources/) | 原始素材：两份转写、三份大纲、PeerReview。只读，不在这里改成稿 |

打磨某一集：打开 `series/EP##-短标题/`，改 `稿.md`，同步 `配图.md`，成品图放进 `figures/`。
