# 配图归档与命名 SOP

打磨某一集时，只打开该集文件夹：`稿.md` + `配图.md` + `figures/`。

## 文件名

本集图：`figures/F##-短名.ext`  
例：`series/EP01-接龙机器/figures/F01-输入法联想.png`

共用图：`series/_shared/figures/S-短名.ext`  
`S-` = shared。查族谱栏目框、写下/学出跷跷板、幕间标题卡放这里。

| 规则 | 做法 |
|---|---|
| 镜号 | 每集从 `F01` 起，按口播出现顺序，两位数字 |
| 短名 | 3–8 个汉字或英文，不加集号（集号已在目录里） |
| 扩展名 | 静帧 `png` 或 `svg`；动画源文件可 `mp4` / `gif` / `mov`，成片仍导出一帧 png 作封面 |
| 禁止 | 空格、`图1.png`、`final_final_v3.png`、把集号写进文件名两次 |

## 形式标签

`示意图` `动画` `表格` `实物` `屏幕录制` `插画` `热力图` `对照图` `截图` `漫画` `流程动画`

## 每集 `配图.md`

| 镜号 | 文件 | 形式 | 画面（一句话） | 状态 | 版权 |
|---|---|---|---|---|---|
| F01 | `figures/F01-输入法联想.png` | 屏幕录制 | 手机输入法打「今天天气」 | 待制 | 自摄 |

状态：`待制` → `草稿` → `定稿`。  
版权：`自绘` `自摄` `公有领域` `需授权` `截图-自有界面`。

待制行可以没有文件，表里先占镜号。定稿才把文件放进 `figures/`。

## 正文标记

```
【配图 F01】屏幕录制：……  （`figures/F01-输入法联想.png`）
```

查族谱固定栏目引用共用框：`_shared/figures/S-查族谱框.svg`。

## 增删改

- 增：下一号接着编，不同时改已定稿文件名。
- 改画面：改 `配图.md` 的「画面」列和稿里说明，文件名尽量不动。
- 作废：表里标 `作废`，文件移到 `figures/_废弃/`，**不复用该镜号**。

## 一集打磨顺序

1. 改 `稿.md`。  
2. 同步 `配图.md`。  
3. 出图进 `figures/`，状态改 `定稿`。  
4. 不在这一集文件夹外改别的成稿。
