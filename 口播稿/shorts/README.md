# 短视频系列「AI 原来如此」

> 《从 0 和 1 到 AI》系列的短视频线。基于长视频文稿**重构**而成，不是切片。每条 80–120 秒，只讲清楚一个“原来如此”。
> 平台：TikTok / 抖音（华语观众）。形式：真人出镜 + 画面穿插。
> 当前进度：**第一幕样片 10 条**（对应长视频 EP01–03）。确认格式后再做第二到第四幕。

---

## 一、和长视频的区别

| | 长视频 | 短视频 |
|---|---|---|
| 单元 | 一集讲一条历史线 | 一条只讲一个“原来如此” |
| 开头 | 可以铺垫 | 前 3 秒必须是反常识的问题、结论或画面，不说“大家好” |
| 结构 | 钩子 → 拆开 → 往下挖 → 往上看 → 查族谱 | 钩子（0–5 秒）→ 讲清楚（5–60 秒）→ 反转 / 意义（60–80 秒）→ 勾下一条（80–90 秒） |
| 字数 | 约 3000 字 | 口播约 300–450 字（80–120 秒） |
| 历史与哲学 | 完整展开 | 最多一个人名、一个年份、一句金句 |

## 二、系列规则

1. **编号**：封面左上角固定角标「AI 原来如此 #NN」，话题标签 #AI原来如此。
2. **时长**：以 90 秒左右为目标；概念复杂的可以到 120 秒；**少于 80 秒的，和相邻的一条合并**。
3. **每条独立**：不说“上一条讲过”，用到前面的概念就给一句话的最小定义。
4. **结尾勾下一条**：最后 5–10 秒抛出下一条要回答的问题，配“合集”引导。
5. **事实**：一律以长视频里已校正的版本为准。
6. **查族谱角标**（可选）：只在主题恰好适合时，用 3 秒角标带过，和长视频的“查族谱”栏目呼应。
