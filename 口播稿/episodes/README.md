## 四、标记约定

| 标记 | 含义 |
|---|---|
| `【配图】` | 编辑建议的画面：画什么，以及用什么形式（示意图 / 动画 / 表格 / 实物 / 屏幕录制） |
| `【补充】…【/补充】` | Claude 新增或重写的段落，用 Steven 的口吻写，方便区分原话 |
| `【校注】` | 事实或用词修正：原话 → 改后 → 理由 |
| 正文其余部分 | Steven 原话的清洗版：去掉口头禅堆叠、重复、闲聊，保留口语风格 |

第二说话人（稿1）的好观点已并入正文（例如“有朋友跟我说……”），闲聊删除。
