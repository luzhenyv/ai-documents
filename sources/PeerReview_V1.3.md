## 二、全局问题（按严重程度排序）

### 1. 理论缺位：讲了“像什么”，没讲“是什么”

**问题。** 几乎每一个核心概念，都停在比喻那一层。
- 马尔可夫链只说了“在当前状态下，转移到下一个状态的概率是多少”（EP01）。
- 注意力只说了“去图书馆找资料”（EP08）。
- 梯度下降有数字，却没有更新规则本身（EP06）。

**为什么这是问题。** 比喻是入口，不是终点。一个读者读完 EP01，应该能说出“转移矩阵每一行加起来等于 1”，也应该能自己算出一个 bigram 概率。否则这个系列和市面上的“AI 名词科普”没有本质区别，而“深入浅出”恰恰应该是它的特色。

**修改建议。** 每一集找到它的“最小理论单元”：一个定义、一个公式、一次手算。写法是讲课式的：
> 故事 → 直觉 → “我们把它写下来” → 定义 / 公式 → 用故事里的数字算一遍 → 回到故事

不加框，不加“【深入】”记号，让它水到渠成。录制时可以一带而过，文字稿要写完整。

**示范：EP01 的马尔可夫链**（已在修订版 EP01 中落实）。马尔可夫自己的数据就是一个完美的教学例子：
- **状态空间**：{元音, 辅音}
- **转移矩阵**：

  |  | → 元音 | → 辅音 |
  |---|---|---|
  | 元音 | 0.128 | 0.872 |
  | 辅音 | 0.663 | 0.337 |

  每一行加起来等于 1。
- **平稳分布**：设长期来看元音占 π，那么 π = 0.128π + 0.663(1 − π)，解得 π ≈ 0.432。而马尔可夫实际数出来的元音比例，正是 43.2%。
- 这一个计算，同时讲清了状态、转移、转移矩阵和平稳分布，还自带“理论预测和现实对上了”的高潮。

### 2. 核心概念缺失：有四个洞，其中一个是全季最大的漏洞

**(a) RLHF / 指令微调：全季最大的漏洞。**

EP01 讲“大模型是接龙机器”，EP08 讲 GPT 走了 Decoder 的路，然后……ChatGPT 就出现了。中间缺了最关键的一步。

一个纯粹做接龙的预训练模型，你问它“世界上最高的山是什么山？”，它很可能接出“世界上第二高的山是什么山？世界上最深的湖是什么湖？”。因为在互联网上，这类问题最常出现在一份题目清单里。

让接龙机器变成“会回答问题的助手”的，是 2022 年 OpenAI 的 InstructGPT 论文：先用人写的示范回答做**指令微调**，再让人给多个回答排序，训练一个**奖励模型**，最后用强化学习去优化（**RLHF**）。它的论文里有一个著名的结果：13 亿参数、经过 RLHF 的模型，比 1750 亿参数的原始 GPT-3 更受人喜欢。

**建议**：并入 EP08 结尾（从 GPT-3 到 ChatGPT），在 EP01 埋伏笔（“它为什么会‘回答’，而不是接着出题？”），在 EP10 回收（“奖励”这个词）。

**(b) 幻觉。** 接龙机器的目标是接出“最像下一个字”的字，而不是“真的”字。这是它一本正经胡说八道的根本原因，和 EP01 的主题直接相关，却一个字都没提。**建议**：写进 EP01；EP03 用“真理不是一个方向”回收。

**(c) 泛化与过拟合。** 机器学习最核心的一对概念，只在 EP07 的彩蛋里出现过一次。没有它，读者无法理解“学出规则”到底难在哪。**建议**：写进 EP04，配合“鹈鹕骑自行车”和“罗素的火鸡”。

**(d) Scaling Law 与“涌现”之争。** EP07 把 AlexNet 标为“新物种”，EP08 把上下文学习标为“新物种”，理由都是“规模带来了意外”。可是全季没有一句话讲规模到底怎么带来能力：没有 Kaplan 2020 的幂律，没有 Chinchilla 2022，也没有 2023 年“涌现是不是测量方法造成的海市蜃楼”的反驳。**这让全季仅有的四个“新物种”标签，缺少证据支撑。** **建议**：写进 EP07 后半，并把反驳写成“最强反方”。

**(e) “Agent”这个词的出身。** EP10 讲了循环和停机问题，但没有给出 Agent 的定义。这个词在 AI 教科书里有非常明确的出处：Russell 和 Norvig 定义为“通过传感器感知环境、通过执行器作用于环境的任何东西”。它和强化学习里的“智能体—环境—奖励”循环一脉相承。**建议**：EP10 开头给出定义。

### 3. “查族谱”标签：单调，而且没有判定标准

15 个标签里有 11 个是“重新组合”。V1 审稿时的警告应验了：**反炒作本身也会变成一种炒作**，读者读到第五集就能猜到结尾。

按作者的决定，“查族谱”改为**可选**。但只要出现，就应该遵循统一标准：

| 标签 | 判定标准 |
|---|---|
| 改了名 | 机制几乎没变，只是名字换了（需要能指出“同一个东西”的证据） |
| 重新组合 | 零件都是已知的，但组合方式带来了**可以描述的**新能力 |
| 新物种 | 出现了**以前原理上做不到、而且有证据**的能力 |

另外，EP05“改了名”的依据（“2006 年辛顿把神经网络改名为 Deep Learning”）**站不稳**：“deep learning”这个术语在 1986 年（Dechter）和 2000 年（Aizenberg 等）就已经出现，2006 年更准确的说法是辛顿团队的“深度信念网络”让这个词流行了起来。建议改为“重新组合”，或者把理由写成“让这个说法流行起来”。

### 4. 故事密度不均，今天的案例几乎为零

**故事足的集**：EP01（马尔可夫、中文屋）、EP05（1958 年的报道）、EP07（李飞飞、辛顿、黄仁勋）、EP10（瓦特、图灵）。

**偏“讲解”、故事少的集**：EP02（后半）、EP04、EP09、EP12、EP13。

**全季都缺的**，是**今天正在发生的事**。系列的定位是“以今天的 AI 为入口”，可正文里的“今天”，基本停留在“AI 能写代码”这个层面。2026 年这一年，就有大量真实、具体、戏剧性的案例：Agent 越狱、Agent 集体攻击外部网站、模型给未来的自己写越狱指令、AI 破译 Enigma 电报……详见第四节。

## 三、新写法规范（按作者决定）

1. **理论融入正文**：铺垫 → 直觉 → 定义 / 公式 → 手算 → 回到故事。不用框，不刻意强调。
2. **每集结尾必备**：
   - **本集小结**：3–5 条要点；
   - **总结**：一段话，把本集放回全季主线；
   - **参考文献**：论文、书、文章、事件报道，事件类注明核实程度。
3. **可选**：查族谱（按第二节第 3 条的标准）、最强反方。
4. **交叉引用**：文字稿里正常使用“见 EPxx”。
5. **标记体系不变**：`【配图】`、`【补充】…【/补充】`、`【校注】`。

## 五、逐集意见

每集三栏：**补理论**（融入正文）/ **补故事、思想家、今天的案例** / **其他问题**。

### EP01 接龙机器
- **补理论**：
  - 马尔可夫链：状态、转移矩阵、平稳分布 ≈ 43.2%（见第二节第 1 条）；
  - n-gram：P(wᵢ | wᵢ₋₁) = 次数(wᵢ₋₁ wᵢ) / 次数(wᵢ₋₁)；
  - 语言模型的链式分解：P(w₁…wₙ) = ∏ P(wᵢ | w₁…wᵢ₋₁)，这就是“接龙”的数学定义；
  - softmax 与温度：pᵢ = exp(zᵢ/T) / Σ exp(zⱼ/T)，配一组数字手算。
- **补故事**：香农 1948 年的“逐级近似英语”；维基百科随机词条技巧；幻觉（接的是“像”，不是“真”）；为 RLHF 埋伏笔。
- **其他**：“有朋友说”保留追星一处。

### EP02 万物皆数
- **补理论**：bit 的定义；信息熵 H = −Σ p log₂ p（抛硬币 = 1 bit）；**交叉熵就是大模型的训练目标**，把香农和今天的大模型直接接起来；BPE 合并过程手算一遍。
- **补故事**：布尔 1854 年《思维的规律》；**香农 1937 年的硕士论文**：继电器电路可以实现布尔代数，常被称为“史上最重要的硕士论文”。它把“0 和 1”从哲学变成了机器，是本集缺失的一环。
- **其他**：“八卦 vs 比特”一段措辞偏主观，保留，但加一句对照：比特“一位一义”的设计，正是为了可以计算信息量。

### EP03 意义住在哪里
- **补理论**：向量、点积、余弦相似度的公式，用两个二维向量手算一遍；Skip-gram 的训练目标（最大化“给定一个词，它的邻居出现”的概率）。
- **补故事**：
  - 索绪尔 1916 年：“语言中只有差异”，比 Firth 更早的关系论意义观；
  - 弗雷格的“晨星与暮星”：同一个指称，不同的意义；
  - 符号接地问题（Harnad 1990）：正好是本集结尾那个问题的学术名字；
  - **真理不是一个方向**（见第四节），写成“最强反方”。
- **其他**：“球面”比喻的校注可以写进正文（归一化之后只看方向）。

### EP04 规则写不完
- **补理论**：Mitchell 1997 年的定义（在任务 T 上，以指标 P 衡量，随经验 E 而提升）；训练集与测试集；**过拟合与泛化**，也就是背答案和学会的区别。
- **补故事**：
  - **鹈鹕骑自行车**；
  - 罗素的“归纳主义火鸡”：每天九点被喂食，直到圣诞节前夜；它说明从数据中学规则有根本局限，是休谟归纳问题的通俗版；
  - 莫拉维克悖论：对人难的（下棋）对机器容易，对人容易的（走路、认猫）对机器难，和波兰尼悖论互为表里。
- **其他**：塞缪尔那句定义改为“常被概括为”。

### EP05 一条直线的失败
- **补理论**：感知机的学习规则 w ← w + η(y − ŷ)x，用 AND 门手算两轮；决策边界 w·x + b = 0；“线性可分”的定义。
- **补故事**：麦卡洛克和皮茨 1943 年的神经元模型（一个神经生理学家和一个流浪少年天才）；罗森布拉特与明斯基都毕业于布朗克斯科学高中；罗森布拉特 1971 年在 43 岁生日那天划船遇难。
- **其他**：“改了名”的依据站不稳，见第二节第 3 条。

### EP06 蒙着眼下山
- **补理论**：均方误差公式 L = (1/n) Σ(ŷ − y)²；梯度的定义；更新规则 θ ← θ − η∇L，用本集的数字验证 ∂L/∂k = 13；链式法则与计算图（一个两层的小例子）；训练集和验证集（接 EP04）。
- **补故事**：沃博斯 1974 年的博士论文（反向传播的早期提出者，却长期被忽视）；**蒸馏**。
- **其他**：“盲眼钟表匠”保留。

### EP07 游戏显卡救了 AI
- **补理论**：为什么神经网络就是矩阵乘法（y = Wx）；FLOPs 的概念；摩尔定律与约 2005 年登纳德缩放终结，单核不再变快，于是计算转向并行；阿姆达尔定律；**Scaling Law**（Kaplan 2020 的幂律，Chinchilla 2022 的“数据和参数要一起放大”）。
- **补故事**：“涌现是海市蜃楼吗？”（Schaeffer 等 2023），作为“新物种”判断的最强反方。
- **其他**：“新物种”的判断要么补上证据，要么降为“重新组合 + 争议”。

### EP08 注意力
- **补理论**：Attention(Q, K, V) = softmax(QKᵀ / √d) V，用 3 个词、2 维向量的数字例子手算一遍；位置编码；O(n²)。
- **补故事**：**RLHF / InstructGPT**（本集结尾新增一节“从 GPT-3 到 ChatGPT”）；论文标题致敬披头士的《All You Need Is Love》。
- **其他**：“上下文学习”被标为新物种，但正文没有例子，需要补一个 few-shot 的例子。

### EP09 AI 没有手
- **补理论**：函数签名；JSON Schema 如何描述参数；RPC 的“存根”（让远程调用看起来像本地调用的那层代码）。
- **补故事**：**提示注入**（配奥斯汀的适切条件）；**责任真空**。
- **其他**：结尾的问题“该怪说的，还是做的”，现在可以用真实讨论来支撑，但仍然不给答案。

### EP10 谁决定何时停
- **补理论**：Agent 的教科书定义；强化学习的“智能体—环境—奖励”循环；停机问题的对角线形式（可以和 EP03 的“真理探针”并列）。
- **补故事**：
  - Shakey 机器人与 STRIPS 规划（1966–72），第一个会“自己想下一步”的机器人；
  - **古德哈特定律 + ExploitGym 事件**；
  - **Enigma 破译**。
- **其他**：这是全季今天的案例最有冲击力的一集，要注意篇幅，建议 ExploitGym 为主、Enigma 为辅。

### EP11 回到命令行
- **补理论**：进程、标准输入 / 输出 / 错误、退出码；“一切皆文件”。
- **补故事**：汤普森为了在一台闲置的 PDP-7 上玩自己写的游戏《Space Travel》，顺手写出了 Unix 的雏形；Ambiance（“模型的先验是最便宜的资源”）。

### EP12 协议即权力
- **补理论**：协议三要素（语法、语义、时序）；**梅特卡夫定律**（网络价值约与 n² 成正比），解释“为什么烂标准也赢”；**路径依赖与锁定**（Paul David 1985）。
- **补故事**：TCP/IP 与 OSI 的“协议战争”（委员会设计的完美标准，输给了能跑起来的那个）；QWERTY；VHS 与 Betamax；MCP 工具投毒。

### EP13 上下文是稀缺资源
- **补理论**：上下文窗口以 token 计；KV Cache 的显存公式（层数 × 2 × 隐藏维度 × 序列长度 × 字节数）；**局部性原理**（Denning 1968 的工作集），它是虚拟内存和 Skill 能成立的理论原因。
- **补故事**：米勒 1956 年的《神奇的数字 7±2》（人的工作记忆）；**OpenAI 模型给未来的自己写越狱指令**。
- **其他**：“30% 经验值”要么给出处，要么只保留“很多人的经验”这层意思。

### EP14 Skill
- **补理论**：产生式规则（IF…THEN…）、推理机、知识库，这是专家系统的三件套；**《没有银弹》的本质复杂度与偶然复杂度**。
- **补故事**：Cyc 项目（1984 年至今，四十年手写常识）；框架问题（McCarthy & Hayes 1969）；费根鲍姆的“知识就是力量”；电商实测（标注来源）。

### EP15 马具
- **补理论**：进程与线程；并发与并行的区别；**最小权限原则**（Saltzer & Schroeder 1975）；阿姆达尔定律（子 Agent 的并行上限）。
- **补故事**：三篇 Harness 文章；ExploitGym 的沙箱失守；Agent 自建留言板；Replit 删库事件（2025-07，待核）。
- **其他**：结尾“马会不会自己造马具”，Lilian Weng 那篇给出了真实的研究进展，可以从一个修辞问句变成一个有根据的问题。

### EP16 旧零件，新胶水
- **补理论**：符号主义与联结主义，给“两条河”一个正式的名字。
- **补故事**：1956 年达特茅斯会议（“人工智能”一词的诞生）；Paul Graham《Taste》；artfish 与《完美匹配》；《渐快》；鹈鹕测试的回收；“Dario, Please”的囚徒困境一句。
- **其他**：三处【待补录】仍需作者本人完成。
